# P3 收口：有界异步批量证据包与复核输入

## 结论与范围

本报告汇总 P3-0…P3-3 的技术交付、命令、失败与未覆盖项，作为 **P3-4 收口材料
和组织级复核输入**。它不宣称 P3 已复核、已签署或已关闭，也不勾选 7-A；P3 的
关闭需要独立组织级复核记录。P3 范围仍限有界单核、`K=4`、`FAIR_QUOTA=2`、
每会话 5 页与既有 `MAX_PROXIES/MAX_CLIENTS` 预算；不包含 SMP、恢复/去重与性能
门槛。

## 失败历史与限制（保留）

- **P3-2 C 数据面 fork 反例**：W6/W7b 曾因 `prima_bulk_close` 只关 v1 页导致子
  进程继承 v2 会话与映射；修复后 V4 同时验证 v1 探针与 v2 数据面并存。
  [报告](2026-11-24-p3-frontend-v2-data-plane.md)。
- **V4 悬挂**：per-op 失败未推进生产者序号；修复后由 V4 覆盖。
- **P3-2 控制面锁**：数据面拆分后控制面仍跨 IPC 持表锁；`0f65768` 完成，但并发
  控制面语义弱化（并发 `close`/`getdents` 缓存竞争、并发 `chdir`/`termios` 最后
  写者、`mkdir`+`chmod` 窗口）登记在
  [控制面锁报告](2026-11-25-p3-adapter-control-lock.md)。
- **认领后取消不可达**：单线程 Store 在一条 doorbell 消息内认领并完成，
  `Cancel::Claimed`/`EALREADY` 只有 host 状态机证据。
- **发布页改写快照**：doorbell 后客户端改写与 Store 读页存在竞态，未单独取证；
  `replay` 只证明重复 doorbell 不新增批。
- **公平性是进展证据**：不测量跨会话吞吐或每轮配额时序。
- **单侧退出**：证明存活会话继续完成，不直接观察死会话槽位回收时刻。
- 无 SMP、恢复/去重、性能门槛；未新增 syscall；未改写 v1 与既有 72 轮事件。

## 未覆盖项（复核输入）

1. P3 契约中“认领后取消”“页改写快照”两项的机器证据；是否接受 host 状态机
   证据或需在 P5/P6 范围补齐。
2. 并发控制面弱化语义是否满足 P3 的可接受边界；是否要求恢复串行或另立契约。
3. 单核有界范围外：SMP/AP、恢复 epoch 与去重、性能门槛仍属后续轨道（7-B/7-D/
   7-G 或 P5/P6）。
4. P3 未做组织级独立复核；本报告不代替复核结论。
