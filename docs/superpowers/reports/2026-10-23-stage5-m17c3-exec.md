# 阶段 5 / M17c-3：exec_replace 打通（W7）

**日期**：2026-10-23
**范围**：`SYS_EXEC_REPLACE(55)` 的内核实现（地址空间替换、初始栈、argv）+
最小探针。**无 VFS 文件来源**：探针在内存中嵌入 530 字节静态 ELF。
**结论**：W7 探针 QEMU 通过：
`EXEC|exec=1;wait=1;bad=1|ok=1;err=0`。

## 1. 实现

| 位置 | 变更 |
|---|---|
| `prima-abi` | `SYS_EXEC_REPLACE = 55` |
| `kernel/src/exec.rs` | `plan_len(image_prefix, image_len)`：段边界按完整镜像长度校验（头前缀即可解析）；`plan()` 为其完整镜像包装 |
| `kernel/src/syscall.rs` | `exec_call`：copy-in ELF 头/程序头（≤288 B）→ `plan_len` → copy-in argv（≤4 项、每项 ≤64 B）→ `bootstrap::exec_teardown` 拆当前任务的模型映射（`BadRoot` 容忍）→ 按 `PT_LOAD` 分配帧并复制（`memsz` 余部清零）→ 固定 VA 栈（`0x7f00_0000_0000`）`build_stack`（`AT_PAGESZ`/`AT_ENTRY`）→ `rip=e_entry`、`rsp=layout.rsp`、`fs_base=0` → `sched::resume(current)` |
| `bootstrap` | `exec_teardown(caller, root, offset)`：逐条 unmap + 清模型条目（不销毁任务） |
| 探针 | `stage5_exec.c`：fork 子进程用内存中的静态 ELF exec，ELF 以 `argc` 为退出码；负例为 8 字节截断镜像（`ENOEXEC` → 子进程以 1 退出） |
| host | 新增 `plan_len_accepts_prefix_with_segment_bound_checked_against_length` |

## 2. 证据

```text
EXEC|exec=1;wait=1;bad=1|ok=1;err=0
```

- `exec=1`：子进程 exec 后以 `argc=2` 退出，父进程 wait4 状态 2；
- `bad=1`：截断镜像返回 `ENOEXEC`，子进程以 1 退出；
- 全量回归：`cargo xtask test` **111 条 PASS，退出码 0**（W7 双轮 + 既有
  W6/W8/W9/其余轮次全量重跑）；
- `cargo test --workspace` 全绿、`cargo xtask lint` PASS。

## 3. 边界

- 只支持静态 `ET_EXEC`（无 PIE/解释器/动态链接）；
- 镜像来源是**调用者内存**（探针内嵌 ELF），未接 VFS `execve` 文件读取；
- 新段的帧归属调用者的映射段（随进程退出释放）；
- 无 `CLOEXEC`、无 `envp`、无 Linux 同源（微小 ELF 使用 Prima 原生 exit 54）；
- 栈固定单页、argv ≤4 项。

## 4. 本报告不代表

- 不表示 `execve` 路径（VFS）可用；
- 不表示阶段 5 退出条件满足。
